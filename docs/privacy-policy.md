# userscript-vault 개인정보 처리방침

최종 수정: 2026-10-12

## 요약
userscript-vault는 **어떤 개인정보도 수집·저장·전송하지 않습니다.** 서버가 없으며, 외부로 나가는 네트워크 요청이 전혀 없습니다.

## 저장하는 데이터
사용자가 직접 만든 다음 항목만 **사용자 브라우저 내 로컬 저장소(`chrome.storage.local`)**에 저장됩니다.
- 등록한 도메인(호스트명)
- 사용자가 작성한 스크립트 이름·본문·실행 컨텍스트(world) 설정

이 데이터는 사용자의 기기를 떠나지 않습니다. 브라우저 동기화(`chrome.storage.sync`)를 사용하지 않으므로 다른 기기로도 전송되지 않습니다. 개발자나 제3자는 이 데이터에 접근할 수 없습니다.

## 데이터 전송·공유
없습니다. 확장은 분석 도구, 원격 서버, 광고, 추적기를 포함하지 않습니다.

## 권한 사용
- `userScripts`: 사용자가 작성한 스크립트를 사용자의 명시적 클릭으로 현재 탭에 실행하기 위함.
- `storage` / `unlimitedStorage`: 위 데이터를 로컬에 저장하기 위함.
- `activeTab`: 현재 탭의 호스트명을 읽어 해당 도메인의 스크립트만 표시하기 위함.
- 사이트 접근 권한(`<all_urls>`, 선택적): 사용자가 도메인을 추가할 때만 그 도메인에 한해 개별 요청합니다. 기본 상태에서는 어떤 사이트 접근 권한도 갖지 않습니다.

## 데이터 삭제
확장을 제거하면 로컬 저장 데이터가 함께 삭제됩니다. 확장 내에서 개별 도메인·스크립트를 삭제할 수도 있습니다.

## 문의
이 확장은 개인/소규모 도구로 제공됩니다. 문의는 배포 페이지를 통해 해주세요.
