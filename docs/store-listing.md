# 크롬 웹스토어 제출 패키지

배포 전 사람이 채워야 하는 항목을 모았다. 업로드 파일은 git repo가 아니라 빌드된 zip 하나다.

## 업로드 파일
- `userscript-vault/userscript-vault-v0.1.0.zip` (`npm run build` 후 `dist/`를 압축한 것)
- 재생성: `npm run build && cd dist && zip -rq ../userscript-vault-v0.1.0.zip . -x "*.DS_Store"`

## 개발자 대시보드 입력값

### 스토어 등록정보
- **이름**: userscript-vault
- **요약 (최대 132자)**: 특정 사이트에서 내 스크립트를 버튼 한 번으로 실행하는 개인용 도구. 자동 실행 없음, 외부 전송 없음.
- **자세한 설명**:
  ```
  특정 웹사이트에서 실행할 자바스크립트를 도메인별로 저장하고, 툴바 팝업의 "실행" 버튼으로 현재 탭에 직접 주입합니다.

  - 도메인(호스트명) 하나에 스크립트 여러 개. 서브도메인 포함 옵션.
  - 자동 실행이 없습니다. 스크립트는 저장만 되고, 직접 "실행"을 눌러야 그때 한 번 주입됩니다.
  - 실행 컨텍스트 선택: USER_SCRIPT(격리) 또는 MAIN(페이지 전역 접근).
  - 모든 데이터는 로컬(chrome.storage.local)에만 저장됩니다. 네트워크 전송·동기화가 전혀 없습니다.
  - 전체 데이터를 zip으로 내보내고 가져올 수 있습니다.

  Tampermonkey 같은 도구의 가벼운 대안으로, 외부로 아무것도 내보내지 않는 것을 최우선으로 설계했습니다.
  ```
- **카테고리**: 개발자 도구 (Developer Tools)
- **언어**: 한국어

### 개인정보 보호 관행 (Privacy practices) — 심사 필수
- **단일 목적 설명**: "사용자가 저장한 자바스크립트를 사용자의 명시적 클릭으로 현재 탭에 실행하는 도구."
- **권한 사유**:
  - `userScripts`: 사용자가 작성한 스크립트를 실행하기 위함.
  - `storage` / `unlimitedStorage`: 스크립트와 설정을 로컬에 저장하기 위함.
  - `activeTab`: 현재 탭 호스트를 읽어 해당 도메인의 스크립트만 보여주기 위함.
  - `optional_host_permissions <all_urls>`: 사용자가 도메인을 추가할 때만 그 도메인에 대해 개별 요청. 기본값으로는 아무 사이트 권한도 갖지 않음.
- **데이터 사용 공개**:
  - 개인정보/사용자 데이터를 **수집·전송하지 않음**. 모든 항목 "아니오".
  - 제3자 전송 없음, 판매 없음, 신용 목적 사용 없음.
- **개인정보 처리방침 URL**: `docs/privacy-policy.md` 작성 완료. 공개 위치(GitHub Pages/Gist 등)에 올리고 그 URL을 대시보드에 기입. 데이터 수집이 없어도 userScripts 확장은 URL을 요구할 수 있음.

## 심사 주의
`userScripts`는 임의 코드 실행 권한이라 심사가 깐깐하고 수일 걸릴 수 있다. 설명에 "자동 실행 없음·외부 전송 없음·사용자 클릭으로만 실행"을 분명히 둔 이유다. 거절 시 사유에 맞춰 설명을 보강한다.
