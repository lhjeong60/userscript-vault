# 수동 QA 체크리스트

이 확장에는 자동 실행이 없다. 스크립트는 저장만 되고, 팝업 **실행** 버튼으로만 현재 탭에 주입된다.

`npm run e2e`(Playwright, 실제 Chromium)가 다음을 자동으로 덮는다: 단계별 노출(온보딩→스크립트→에디터), 저장해도 등록 0건·페이지 로드로 실행 안 됨, execute 경로(USER_SCRIPT 격리/MAIN 전역 접근), 도메인 편집(호스트·서브도메인), 대화상자 Esc 취소, 미저장 가드, 도메인 전환 시 에디터 닫힘, 내보내기→초기화→가져오기 왕복(동명 스크립트·world 보존), 재가져오기 건너뛰기, 손상 zip, 잘못된/중복 호스트, 팝업 실행 버튼·비http 탭.

아래 **[수동]** 표시는 자동화 불가(네이티브 권한 프롬프트, 실제 활성 탭 컨텍스트). 나머지는 e2e 회귀 시 참고용.

## 준비
- [ ] `npm test`, `npm run build`, `npm run check:privacy` 전부 통과
- [ ] `chrome://extensions`에서 `dist/` 로드, 세부정보 → "사용자 스크립트 허용" 켜짐 (Chrome 135+)

## 실행 (execute)
- [ ] **[수동]** 도메인 추가 → 권한 프롬프트 허용 → 스크립트 작성·저장 → 해당 사이트 탭에서 팝업 **실행** → 즉시 적용, "실행함" 알림
- [ ] **[수동]** world MAIN → 페이지 전역 접근 (예: `document.title = typeof window.jQuery`), USER_SCRIPT → 격리 확인
- [ ] 저장만 하고 페이지를 새로고침/재방문 → 아무 것도 실행되지 않음 (자동 실행 없음)
- [ ] **[수동]** 서브도메인 체크 → 두 번째 권한 프롬프트 → `sub.host` 탭에서 실행됨
- [ ] "사용자 스크립트 허용"이 꺼져 있으면 팝업·옵션 상단 배너 표시, 실행 버튼 비활성

## 옵션 페이지
- [ ] 도메인 없음 → 온보딩 카드만. 도메인 선택 전 → 도메인 목록만. 스크립트 선택 → 에디터
- [ ] `GitHub.com/foo` 입력 → `github.com`으로 정규화되어 등록
- [ ] **[수동]** 권한 프롬프트 거부 → "사이트 접근 권한이 필요합니다", 도메인 생성 안 됨
- [ ] 새 스크립트 → `script-N` 생성, 이름 입력창 포커스. 자동 실행 관련 컨트롤 없음
- [ ] world 드롭다운 변경·이름 변경·본문 편집 → "변경됨" → `Cmd/Ctrl+S` → "저장됨. 팝업 \"실행\"으로…"
- [ ] 저장 안 한 변경 상태에서 다른 스크립트/도메인 이동 시 확인 대화상자 (취소/버리기)
- [ ] 확인 대화상자를 한 번 "확인"으로 닫은 뒤, 다른 확인 대화상자를 Esc로 닫으면 **취소**로 처리됨 (returnValue 잔존 회귀)
- [ ] 도메인 B로 전환 → 에디터 닫힘(stage=scripts)
- [ ] 문법 오류(`const x = ;`) 저장 시 빨간 상태줄, 코드는 보존
- [ ] 도메인 편집 버튼 → 호스트/서브도메인 변경 → 권한 프롬프트 → 반영. 도메인 삭제(사이트 액세스 권한 반납)
- [ ] 저장 안 한 상태로 탭 닫기 → 브라우저 경고
- [ ] 라이트·다크 모드 둘 다 가독성 (다크 에디터 one-dark)

## 가져오기 / 내보내기
- [ ] 내보내기 → `userscript-vault-YYYY-MM-DD.zip`. 구조: `export.json` + `<host>/<name>.js`, world 포함
- [ ] **[수동]** 확장 제거 → 재설치 → 가져오기 → 충돌 대화상자 → 권한 프롬프트(새 도메인 일괄) → 복원
- [ ] 같은 zip 재가져오기: 건너뛰기 → "추가 0, 덮어쓰기 0, 건너뜀 N". 덮어쓰기 → "추가 0, 덮어쓰기 N, 건너뜀 0"
- [ ] 손상 zip(텍스트 파일 이름만 .zip) → "가져오기 실패: zip 파일을 읽을 수 없습니다", storage 변화 없음
- [ ] **[수동]** 권한 프롬프트 거부 → "가져오기 취소: …", storage 변화 없음

## 팝업
- [ ] **[수동]** 등록 도메인: 호스트명 + 스크립트마다 **실행** 버튼 (스위치 없음). MAIN 스크립트엔 MAIN 태그
- [ ] **[수동]** 미등록 도메인: "이 사이트에 등록된 도메인이 없습니다" + "`host` 추가" → 옵션 페이지 입력창에 호스트 채워짐
- [ ] **[수동]** 가드: `chrome://extensions` 사이트 액세스에서 등록 도메인 권한을 수동 제거 → 그 도메인 탭에서 실행 → "사이트 접근 권한이 없습니다" 안내(raw 오류 아님)
- [ ] 서브도메인 포함 도메인은 `gist.github.com`에서도 표시
- [ ] chrome:// 탭: "여기서는 사용할 수 없습니다"
- [ ] "관리" 버튼 → 옵션 페이지
